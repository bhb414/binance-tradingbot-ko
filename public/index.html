API 키 등록
연결 대상바이낸스 실전 · 실제 계좌

연결에 성공한 키는 이 PC에 Windows 사용자 계정으로 암호화 저장합니다. 같은 계좌의 주문 허용 설정은 재시작 후 복원되고, 봇은 직접 시작합니다. 브라우저에는 키를 저장하지 않습니다.

저장 위치 · 프로그램 삭제 시 처리

API Key와 Secret은 아래 파일에 Windows 사용자 계정으로 암호화 저장합니다.

프로그램 폴더/.runtime/credentials.dpapi

프로그램 폴더를 .runtime 폴더와 함께 삭제하면 로컬 저장본도 삭제됩니다. 실행 파일이나 바로가기만 삭제하면 키 파일은 남습니다. 별도 데이터 폴더를 지정한 경우 그 폴더는 따로 삭제해야 합니다.

이 PC의 저장 키를 삭제해도 바이낸스에서 발급한 API 키 자체는 유지됩니다. 키 발급을 취소하려면 바이낸스 API 관리에서 별도로 삭제하세요.

주문 허용은 위 토글에서 바로 변경합니다. 키를 삭제하면 주문 허용 설정도 해제되고 다음 실행 시 자동 연결하지 않습니다.

프로그램 업데이트

Git 설치 없이 업데이트할 수 있습니다. 공식 릴리즈 ZIP을 검증한 뒤 적용합니다. 프로그램을 종료한 뒤 update.cmd를 실행하고, 완료 후 run.cmd로 시작하세요. 키·봇 설정·매매 기록은 유지됩니다.
