# 바이낸스 자동매매

바이낸스 상품 차트 조회와 **USDT 무기한 선물 자동매매**를 위한 한국어 로컬 앱입니다. 수식 조건·행동, 봇별 예산, 직접 주문, TP/SL, 손익·수수료·펀딩 조회와 캐릭터 사무실을 제공합니다.

**[Windows ZIP 다운로드](https://github.com/bhb414/binance-tradingbot-ko/releases/latest)** · [사용법·수식 문법](docs/USAGE.md) · [변경 기록](CHANGELOG.md) · [문제 신고](https://github.com/bhb414/binance-tradingbot-ko/issues)

## 처음 설치하기

- Windows 10/11
- [Node.js 24 이상](https://nodejs.org/en/download) — 24 버전 기준 검증
- [Git for Windows](https://git-scm.com/downloads/win) — 자동 업데이트에 필요

1. **Windows ZIP 다운로드**에서 최신 배포의 binance-tradingbot-ko-v버전-windows.zip을 받습니다.
2. 원하는 폴더에 **모두 압축 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
3. 폴더 안의 **run.cmd**를 더블클릭합니다. 별도 npm install은 필요 없습니다.
4. 자동으로 열린 브라우저의 **설정 → API 키 등록**에서 본인 계좌의 HMAC API Key와 Secret을 입력합니다.
5. 준비가 되면 **실전 주문 허용** 토글을 켜고, 봇을 만들어 종목·예산·조건을 확인한 뒤 개별 시작합니다.

앱 주소는 [http://127.0.0.1:8896](http://127.0.0.1:8896)입니다. 실행 창을 닫으면 서버와 로컬 조건 감시가 종료됩니다. 바이낸스 공식 제품이 아닙니다.

Git으로 설치하려면:

~~~powershell
git clone https://github.com/bhb414/binance-tradingbot-ko.git "바이낸스 자동매매"
cd "바이낸스 자동매매"
.\run.cmd
~~~

## 지원 범위

| 기능 | 범위 |
| --- | --- |
| 차트 조회 | 바이낸스 USDⓈ-M·COIN-M·현물·옵션에서 공개 조회 가능한 상품 |
| 실제 주문·봇 | USDT를 증거금으로 쓰는 무기한 선물, 계좌·지역별 거래 가능 상품에 한함 |
| 차트·지표 | 일반/하이킨아시 봉, 이동평균·볼린저 등, 수식 지표, 설정 저장 |
| 봇 | 한 봇당 한 종목, 롱/숏 진입·정리·정지 조건, 추가 진입, 중복 주문 방지 |
| 운용 | 예산·손익 반영 방식, 조건별 레버리지, 크로스/격리, 수동 포지션 인수 |
| 작업실 | 사람 캐릭터, 외형 설정, 손익 표정·효과, 우측 봇 목록 |

계좌의 단방향/헤지 모드는 조회하며 임의로 전환하지 않습니다. 같은 종목은 한 봇이 담당하고, 한 봇은 한 시점에 하나의 방향을 보유합니다. 과거 데이터 백테스트·전략 수익성 검증 기능은 포함되어 있지 않습니다.

수식 예시 — 직전 완성된 1시간봉에서 하이킨아시 종가가 볼린저 상단을 상향 돌파:

~~~text
상향돌파(하이킨종가, 볼린저상단(하이킨종가, 55, 1.04))@1h[1]
~~~

## 업데이트

1. 실행 창에서 **Ctrl+C**로 종료합니다.
2. **update.cmd**를 더블클릭합니다.
3. 끝나면 **run.cmd**로 다시 실행합니다. 주문 허용 설정은 같은 계좌에서 복원되고, 봇 신규 진입은 직접 다시 시작합니다.

ZIP 설치본도 업데이트할 수 있습니다. 첫 업데이트에서 공개 버전 태그와 설치 파일을 대조한 뒤 Git 기록을 준비합니다. 변경·누락 파일이 있으면 덮어쓰지 않고 중단합니다. 새 버전은 임시 폴더에서 테스트한 뒤 반영합니다.

설정의 **업데이트 확인**으로 새 버전을 조회합니다. 업데이트 전 원장은 .runtime/backups/에 백업합니다. 키·설정·체결 기록을 배포 파일로 바꾸지 않습니다. 업데이트·서버 종료 중에는 로컬 조건 감시가 멈춥니다.

## 저장 위치와 주문 동작

- .runtime/state.json: 봇 설정, 주문 허용 설정, 주문 의도·체결 원장
- .runtime/credentials.dpapi: 같은 Windows 사용자용으로 암호화한 API 키
- 브라우저 저장소: 관심종목·차트·지표·캐릭터 외형

키·개인 설정·매매 기록은 GitHub와 배포 ZIP에 포함하지 않습니다. 별도 데이터 폴더는 WORKROOM_DATA_DIR로 지정합니다. 앱을 이동할 때는 종료 후 .runtime도 함께 옮겨야 합니다. 암호화 키 파일은 다른 PC나 Windows 사용자로 그대로 옮겨 복호화할 수 없습니다.

**봇 정지**는 신규 진입만 중지하며 보유 포지션의 정리·보호 관리는 이어갑니다. **실전 주문 허용 끄기**는 로컬 주문 실행을 중지하며 기존 포지션·미체결 주문을 취소하거나 청산하지 않습니다.

시세·계좌 조회는 REST 기반입니다. 호출 제한·네트워크 장애 중에는 판단을 보류하고 자동 재개를 기다리므로 조건식 진입·청산이 지연될 수 있습니다. 이미 거래소에 접수된 TP/SL은 거래소에서 처리합니다. 크로스 예산은 주문 산정 한도이며 최대 손실 한도가 아닙니다. 실전 거래·수익을 보장하지 않습니다.
