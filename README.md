# 바이낸스 자동매매

바이낸스 상품 조회와 USDT 선물 조건식 자동매매 앱입니다.

**[다운로드](https://github.com/bhb414/binance-tradingbot-ko/releases/latest)**

## 실행

1. [Node.js 24 이상](https://nodejs.org/en/download)을 설치합니다.
2. 다운로드한 ZIP을 모두 풀고 **run.cmd**를 실행합니다.
3. 설정에서 본인 API 키를 등록하고, 주문 허용을 켠 뒤 봇을 시작합니다.

Windows용입니다. 별도 npm 설치는 필요 없습니다. 주소는 http://127.0.0.1:8896 입니다.

## 다중종목 봇

봇 탭의 **+ 다중종목 봇**에서 2~8종목과 증거금 예산 비중(합계 100% 이하, 남은 비중은 미사용)을 정합니다. 조건마다 종목별 롱·숏 진입, 부분·전량 정리와 레버리지를 지정합니다. 예: `(A.종가 > SMA(B.종가, 20))@1h[1]`. A·B는 설정한 종목 별칭이며, `BTCUSDT.종가`처럼 심볼로 직접 참조할 수도 있습니다.

여러 주문은 각각 체결됩니다. 일부 실패 시 신규 진입을 중지하고 이미 체결된 보유분의 관리를 계속합니다.

## 같은 Wi-Fi에서 접속

서버 PC의 **설정 → 같은 Wi-Fi 접속 허용**을 켜면 휴대폰·다른 PC에서 열 주소와 6자리 코드가 표시됩니다. 같은 공유기에 연결한 기기에서 주소를 열고 코드를 입력하세요. 허용 설정은 재시작 후에도 유지되며, 끄면 다른 기기 접속만 해제됩니다. API 키 관리는 서버 PC에서 합니다.

## 현재 포지션 수익률

봇 목록에서 **평가**와 **비용 후 예상**을 나란히 봅니다. 둘 다 현재 보유 증거금 대비이며, 비용 후 예상은 남은 보유분의 진입 수수료·발생 펀딩·현재 평가가격 기준 시장가 정리 예상 수수료를 반영합니다. 실제 체결가격·주문방식·할인에 따라 달라지며 미래 펀딩은 제외합니다. 부분 정리한 수량의 손익·비용은 남은 포지션에 섞지 않습니다. 비용을 확인할 수 없는 인수 포지션 등은 미확인으로 표시합니다.

## 매매 기록·통계

**활동 기록 → 매매 기록·통계** 또는 봇 **상태·기록 → 매매 기록·그래프**에서 확인합니다. 진입부터 전량 정리까지 묶은 거래별 수수료·펀딩 포함 손익과 수익률, 누적 수익률·금액 추이, 승률·평균 수익률·확정손익 기준 낙폭을 봅니다. 비용이 미확인인 기록은 구분합니다.

## 데이터 수신

**설정 → 데이터 수신**에서 웹소켓(기본) 또는 REST를 선택합니다. REST 조회 간격은 3~300초로 저장되며, 웹소켓이 끊겼을 때의 보완 조회에도 적용됩니다. USDT 선물·현물·COIN-M 시세는 웹소켓 연결을 공유합니다. 계좌 변경 이벤트 뒤 상세 내역을 확인하며 60초마다 대조합니다. 최초 봉 로딩·재연결 복구·주문 전 검증은 REST를 사용하고, 옵션 조회도 REST입니다.

## 업데이트

[Git for Windows](https://git-scm.com/downloads/win) 설치 후 프로그램을 종료하고 **update.cmd**를 실행합니다. 끝나면 run.cmd로 다시 시작합니다. 키·봇 설정·매매 기록은 .runtime 폴더에 보존됩니다.
