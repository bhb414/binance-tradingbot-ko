# KAMA · Hull MA와 교차 주기 분석

지표 목록에서 KAMA, HMA/Hull MA, 교차 주기 분석을 검색해 추가할 수 있습니다. 기존 차트와 봇 설정은 자동으로 바꾸지 않습니다. 이동평균선 묶음의 이평 종류에서도 KAMA·Hull MA를 선택할 수 있습니다.

## KAMA와 Hull MA

- `KAMA(데이터, 효율비율 기간, 빠른 평활 기간, 느린 평활 기간)`: 뒤의 두 기간은 생략하면 2·30입니다. 빠른 기간은 느린 기간보다 작아야 합니다. 처음은 효율비율 기간의 단순평균으로 시작하고, 이후 가격 변화의 효율에 따라 평활계수를 조절합니다.
- `HMA(데이터, 기간)` 또는 `HullMA(데이터, 기간)`: 시간 가중 WMA를 조합합니다. 절반 기간과 제곱근 기간은 소수점을 버리고 최소 1봉을 사용합니다. 기간 20이면 처음 23봉이 준비된 뒤 표시됩니다.
- 두 지표 모두 거래량을 사용하지 않습니다. 거래량 가중 이동평균은 VWMA입니다. 기간은 1~500 정수이며 기본 지표 설정의 입력 범위는 화면을 따릅니다.

지표 만들기에 아래 스크립트를 입력하면 가격 차트 위에 두 선을 표시할 수 있습니다.

```text
선("KAMA", KAMA(하이킨종가, 10, 2, 30))
선("Hull MA", HMA(하이킨종가, 20))
```

## 주기 함수 3개

| 함수 | 결과 |
|---|---|
| 주기추정(값, 조회봉수, 최소주기, 최대주기) | 파형 한 바퀴의 반복 길이 후보(봉 수). 약한 반복·평탄한 값·직선 추세·봉 부족은 미확인입니다. |
| 교차간격(단기, 장기) | 최근 완료된 골든→데드 또는 데드→골든의 봉 수. 다음 반대 교차까지 유지합니다. 같은 방향의 반복 터치는 구간을 다시 시작하지 않습니다. |
| 경과봉수(조건) | 참인 봉은 0, 다음 봉부터 1·2·3…입니다. 참인 봉마다 0으로 돌아갑니다. 첫 발생 전 또는 중간 미확인 데이터 뒤에는 새 발생을 확인할 때까지 미확인입니다. |

조회 봉 수는 16~500, 최소 주기는 4 이상이며 최소 < 최대, 조회 봉 수 ≥ 최대 주기 × 2여야 합니다. 예: 주기추정(7이평−15이평, 200, 8, 100).

주기 추정은 과거 창의 선형 추세를 제거하고 자기상관의 국소 봉우리와 정현파 적합도를 함께 확인합니다. 현재 기준은 상관 0.55 이상·적합도 0.35 이상입니다. 이는 구현의 선별 기준이며 예측 확률이 아닙니다. 추정 주기는 가격 자체와 이평 필터의 성질에 영향을 받으며, 시장에 고정 주기가 있다는 뜻이 아닙니다.

```text
단기 = SMA(하이킨종가, 7)
장기 = SMA(하이킨종가, 15)
선("추정 한 바퀴", 주기추정(단기-장기, 200, 8, 100)[1])
선("최근 완료 간격", 교차간격(단기, 장기)[1])
선("교차 후 경과", 경과봉수(상향돌파(단기,장기) or 하향돌파(단기,장기))[1])
```

지표는 현재 차트 주기를 사용합니다. 함수 뒤 [1]은 직전 완성봉입니다. 봇 조건에서 쓸 때는 함수 전체에 @1m[1]처럼 주기와 기준 봉을 지정합니다. 예: (교차간격(SMA(하이킨종가,7),SMA(하이킨종가,15)) > 20)@1m[1].

## 기본 교차 주기 분석 지표

한 봉 만에 다음 교차가 발생하면 경과 0인 관측점 하나만 남습니다. 이 구간은 방향 색상의 작은 점으로 표시합니다. 중간의 짧은 반대 구간도 빠짐없이 보이며 다른 구간의 선과 연결하지 않습니다. 연결된 일반 경과선에는 점을 추가하지 않습니다.

두 이평이 같거나 계산 반올림 오차만큼 차이 나는 구간은 접촉으로 봅니다. 접촉 중에도 경과 봉 수는 계속 누적하며, 마지막으로 확인된 쪽의 반대편으로 실제 이동했을 때만 새 경과를 0부터 시작합니다. 위→같음→위는 이어지고 위→같음→아래는 마지막 봉에서 새 데드 경과를 시작합니다. 화면에 표시한 소수 자릿수나 거래소 호가 단위로 이평을 반올림하지 않으므로 실제 미세 교차는 유지합니다. 최초 구간에서 한쪽에 있다가 접촉 후 같은 쪽으로 돌아오는 것만으로는 첫 교차를 만들지 않습니다.

지표 설정의 **기준주기 계산 방식**에서 다음 중 하나를 선택합니다. 기존에 저장한 지표는 실측 후보 방식으로 유지합니다.

- **실측 후보**: 실제 단기−장기 이평 차이 파형의 반복 성분을 비교합니다. 기본 SMA 7·15, 조회 200봉, 탐색 8~100봉입니다. 기존의 강한 반복 기준을 통과한 후보가 있으면 우선 사용합니다. 없으면 스펙트럼의 구별 가능한 봉우리 중 설명력이 큰 참고 후보를 표시합니다. 범례에 참고 여부와 파형 설명력을 표시하고, 툴팁에서 최대 3개의 후보를 비교합니다. 설명력은 해당 파동의 적합도이며 예측 확률이 아닙니다. 참고 후보도 배수 보기의 1배로 사용하므로 확정된 시장 주기로 해석하지 마세요. 봉 부족·평탄한 파형·직선 추세는 계속 미확인입니다. 미확인 값을 이론값으로 자동 대체하지 않습니다.
- **SMA 이론 · 공통 기준**: 실제 측정 이평 종류와 관계없이 같은 단기·장기 기간의 SMA 쌍을 공통 참조로 사용합니다. SMA의 복소 주파수 응답 차이 |H단기(ω)−H장기(ω)|가 최대인 주파수에서 주기 2π/ω를 계산합니다. SMA 7·15 기준은 약 20.15봉이므로 실제 측정을 EMA·VWMA·KAMA·Hull MA 7·15로 바꿔도 같은 값을 1배로 사용합니다. 이 값은 다른 이평 자체의 이론 주기가 아니며, 실제 시장의 반복 주기를 보장하지 않습니다.

이론 기준을 선택하면 실측 분석용 조회 봉 수·최소·최대 주기 입력은 비활성화됩니다. 공통 SMA 이론값은 단기·장기 기간을 바꿀 때 다시 계산하며 실제 이평 종류·시세·거래량에 따라 변하지 않습니다. 실제 교차 간격·경과와 실측 후보는 선택한 이평 종류·가격 소스·캔들 기준으로 계산합니다. 범례 머리글은 실제 측정 이평 종류, 기준값은 SMA 이론으로 구분하며 툴팁에서 둘의 기간을 확인할 수 있습니다.

**1배로 사용할 길이**는 선택한 기준주기 전체 또는 그 ½ 중 직접 고릅니다. ½는 사용자의 환산 선택이며 실제 골든→데드가 항상 그 길이라는 뜻이 아닙니다. 예를 들어 전체 기준주기 20봉, 돌파 간격 30봉이면 전체를 1배로 선택했을 때 1.5배, ½를 선택했을 때 3배입니다. 어느 실제 돌파 구간도 자동으로 기본 1배나 반 주기로 정하지 않습니다.

봉 수 보기의 첫 선은 선택한 기준주기이며, 배수 보기의 첫 선은 1배 기준선입니다. 나머지 선은 최근 완료된 반대 돌파 간격과 마지막 돌파 이후 경과입니다. 기준을 바꿔도 실제 간격·경과 봉 수는 그대로이고 나눗셈의 기준만 바뀝니다. 범례에는 이론/실측 후보, 기준 봉 수와 배수를 표시합니다. ¼·½·1·2·3·4배 기준선도 제공합니다. 실측 주기를 찾지 못한 배수 보기에서도 실제 간격·경과 봉 수와 대기 이유를 확인할 수 있습니다.

미래 봉을 사용하지 않습니다. 진행봉 기준은 봉이 끝나기 전 변할 수 있습니다. 새 봉이 추가된다는 이유로 완료된 과거 창을 미래 데이터로 다시 맞추지 않습니다. KAMA처럼 재귀 계산을 하는 이평은 조회 시작점과 초기값이 달라지면 초기 구간의 값이 달라질 수 있습니다.

## 이평 예상

지표 목록에서 **이평 예상**을 추가합니다. 기본 5·20·60·120·220선 다섯 개를 체크박스로 선택하고, 각 선의 종류(SMA·EMA·VWMA·KAMA·Hull MA)·기간(1~300봉)·색상을 따로 정합니다. 예상 봉 수(1~120봉)·기울기 비교 봉 수·기준봉·가격 소스·캔들 기준은 함께 적용합니다. 기본은 최근 3봉 기울기, 직전 완성봉 기준, 3봉 뒤입니다. 실선은 실제 이평, 점선은 최근 기울기가 유지된다고 가정한 예상 경로입니다. 실제 미래 가격·확률·확정 신호가 아니며 교차를 요구하지 않습니다.

범례에는 선택한 선의 종류·기간·색상을 한 번씩 표시합니다. 묶음 숨김과 개별 체크박스는 별개이며 모두 해제해도 설정은 보관됩니다. 스타일 탭에서는 실선과 예상 점선의 색상·두께·표시를 따로 조절할 수 있습니다. 기존 이평 돌파 예상의 두 선은 종류·기간·색상·두께·표시 상태와 예상 설정을 유지해 옮기고, 추가 세 선은 기본으로 해제합니다.
