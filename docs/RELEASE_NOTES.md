# 바이낸스 자동매매 v0.4.46

- 사용자 지표식과 봇 조건식에서 **NW(데이터, 계산 봉 수, Bandwidth)** 지원. 기본 NW 지표의 Gaussian 중심선과 동일한 과거·현재 봉 가중평균을 사용합니다.
- 수식 지표 예제에 **NW + ATR 상단선**, **NW - ATR 하단선**, **NW 중심선**을 추가합니다. 수식 상단·하단은 일반 봉 ATR을 사용하며 기존 NW 평균 절대오차 밴드와 구분합니다.
- 단일·다중종목 편집기에 NW 삽입·예제·인수 도움말을 제공합니다. @봉주기·[1]·발생 횟수·종목별 소스와 조합할 수 있습니다.
- 누락 데이터·준비 봉·인수 범위·계산량을 검사하고 미래 봉에 따른 과거값 변경을 방지합니다. 기존 차트 설정과 봇 전략은 자동으로 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.46-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
