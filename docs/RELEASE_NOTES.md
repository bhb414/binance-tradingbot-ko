# 바이낸스 자동매매 v0.4.92

- 주기분석 예상 화살표를 갱신할 때 기존 표시를 먼저 지우던 동작을 수정합니다. 새 계산이 끝난 뒤 롱·숏 결과를 한 번에 교체해 중간 빈 화면과 부분 표시를 없앱니다.
- 시세가 바뀌어 재계산하더라도 화살표의 위치·색상·문구가 같으면 다시 그리지 않습니다. 실제 조건이 없어지면 완료된 새 결과에 따라 사라지고, 사용자가 숨기면 즉시 숨깁니다.
- 교차 필요가격 툴팁도 바뀐 문구만 갱신합니다. 기존 역산식·표시 배수·주기분석·봇·주문·예산 설정은 유지합니다.
- 툴팁 박스를 누를 때 뒤의 차트·지표 범례까지 눌리던 문제를 수정합니다. 떠 있는 예상 툴팁 안으로 포인터를 옮겨도 유지되며, 박스를 누르면 그 정보를 고정하고 내부 버튼·상세·스크롤만 작동합니다.
- 같은 봉 안의 포인터 이동으로 범례·툴팁을 반복 계산하던 처리를 줄입니다. 빠른 이동은 화면 프레임마다 마지막 위치만 계산하고 숫자 서식을 재사용해 부하를 낮춥니다. 새 시세는 기존대로 반영합니다.
