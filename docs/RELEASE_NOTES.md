# 바이낸스 자동매매 v0.4.74

- **이동평균선 묶음** 지표를 추가했습니다. 기본 5·20·60·120·220선 다섯 개를 한 지표에서 관리합니다.
- 입력 탭에서 선마다 체크박스·기간·색상을 정합니다. 묶음 전체의 이평 종류는 SMA·EMA·VWMA, 가격 소스와 캔들 계산 기준도 선택할 수 있습니다.
- 스타일 탭과 입력 탭의 표시·색상 선택을 동기화하며, 전부 해제해도 기간·색상 설정을 보관합니다. 우측 라벨에는 각 선의 종류·기간을 간단하게 표시합니다.
- 일반·하이킨아시 각 소스의 계산값을 기존 단일 이평과 대조하고 모바일·확대 차트·서버 저장·새로고침 복원을 검증했습니다. 기존 지표·봇 조건과 주문 동작은 유지합니다.
