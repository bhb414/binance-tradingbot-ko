# 바이낸스 자동매매 v0.4.87

- **주기분석 배수 기준선**을 1 이상에서도 **1·1.5·2·2.5…**의 0.5 간격으로 표시합니다. 확대·축소한 화면 범위를 따라 그리며 4배 이후도 이어집니다. 기존 0.25·0.5 기준선과 골든·데드 경과 색상 설정은 유지합니다.
- **가격·보조지표 패널 높이**를 경계선을 놓는 순간 저장합니다. 새로고침 때 공유 지표를 늦게 불러오거나 패널이 다시 만들어져도 지표 ID로 저장한 비율을 복원합니다. 크기는 기존처럼 브라우저의 종목·봉 주기별 차트 설정에 저장합니다.
- 홈 차트의 확대 버튼이 별도 모달 대신 **현재 차트 전체화면**으로 동작합니다. 같은 종목·봉 주기·지표를 유지하며 버튼 또는 Esc로 해제합니다. 브라우저 전체화면을 지원하지 않는 환경에서는 창 전체를 채우는 방식으로 동작합니다.
- 전체화면 안에서도 지표 설정을 열 수 있으며, 설정창을 닫은 뒤 차트 전체화면을 계속 사용할 수 있습니다. 기존 봇·주문·지표 설정은 보존합니다.
