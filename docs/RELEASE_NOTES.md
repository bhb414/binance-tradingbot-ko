# 바이낸스 자동매매 v0.4.91

- 주기분석의 **오른쪽 예상 영역에 십자선을 놓거나 클릭**하면, 다음 N봉 동안 같은 실제 종가가 유지될 때 두 이평이 만나는 가격 경계를 역산합니다. 클릭하면 정보를 고정해 자세히 볼 수 있습니다.
- **`5봉 후 · 20배 변동 −4.20%`**처럼 설정 배수를 곱한 변동률만 간결하게 표시합니다. 원래 가격 변동률을 따로 반복하지 않습니다. 입력 탭의 **교차 필요가격 툴팁**과 **변동률 표시 배수 (레버리지)**로 표시 여부와 배수(기본 1배)를 정합니다.
- **최초 플러스 예상 화살표**는 예상 경과 연장선에서 현재가 대비 처음 플러스가 되는 롱·숏의 미래 봉에 각각 한 번 표시합니다. 롱은 상승, 숏은 하락 변동률을 기준으로 하며 더 이른 교차·접촉이 있는 경계는 제외합니다. 실시간 재계산 시 화살표가 이동하거나 사라질 수 있고 실제 주문 신호가 아닙니다. 입력 탭에서 끌 수 있습니다.
- 필요 종가, 현재 기준종가, 역산 기준, 미래 봉의 가정은 툴팁 상세에서 확인합니다. 기존 경과선의 완성봉·진행봉 선택과 별도로 필요가격 역산은 현재 진행봉까지 반영한 다음 N봉이 기준입니다. VWMA는 미래 거래량을 기준봉과 같게 두고, 하이킨아시는 실제 가정 가격으로 다시 계산합니다. KAMA 등 비선형 계산은 양수 가격의 수치 탐색 결과를 안내합니다.
- 접촉 경계와 엄격한 교차를 구분하고 더 일찍 교차하는 경우도 안내합니다. 가격과 무관하게 두 이평이 같아지거나 계산할 수 없는 경우 특정 가격을 만들어 표시하지 않습니다.
- 변동률은 현재 기준종가에 진입했다고 가정한 가격 변화 × 표시 배수입니다. 숏 수익률은 부호가 반대이며 수수료·펀딩을 제외합니다. 기존 예상선·경과·봇·주문·예산·지표 설정은 유지합니다.
