# 바이낸스 자동매매 v0.4.90

- **주기분석 오른쪽 예상선**을 추가합니다. 경과는 현재 표시값부터 한 봉마다 1씩 올라가는 점선으로, 선택한 예상 기준값은 현재 높이의 가로 점선으로 연장해 만나는 위치를 볼 수 있습니다. 배수 표시는 현재 1배 길이를 고정해 환산합니다.
- 입력 탭에서 **오른쪽 예상선 표시**와 **예상선 표시 봉수**를 정합니다. 기본 26봉, 최대 300봉이며 미리보기에 교점까지의 봉수와 표시 범위 밖 여부를 안내합니다. 기존 골든·데드 경과 색상과 기준선 색상을 이어 사용합니다.
- 기존 완성봉·진행봉 계산 기준을 유지하며 새 값이 수신되면 예상선을 다시 그립니다. 봉 중 변화까지 반영하려면 진행 중인 봉을 선택합니다. 연장선은 현재 구간과 기준값이 유지된다는 가정이며 이후 교차를 확정하는 선은 아닙니다.
- **경과선과 예상 기준값 선은 크로스 이전 점과 새 구간을 연결하지 않습니다.** 새 구간이 0이 아닌 값에서 시작해도 끊으며, 실제 봉 시각·경과 값·계산 결과와 기준주기 선은 유지합니다.
- 범례의 남은 배수·봉수 동시 표시와 기존 봇·주문·지표 설정은 보존합니다.
