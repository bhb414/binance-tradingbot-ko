# 바이낸스 자동매매 v0.4.82

- 교차 주기 분석의 이론 기준을 **같은 기간의 SMA 공통 참조값**으로 통일했습니다. 실제 측정 이평을 EMA·VWMA·KAMA·Hull MA로 선택해도 사용할 수 있습니다.
- 7·15 조합의 공통 이론 기준은 약 20.15봉입니다. 단기·장기 기간을 바꾸면 해당 기간의 SMA 참조값으로 다시 계산합니다. 실제 이평 종류·가격·거래량은 이론 분모를 바꾸지 않습니다.
- 실제 돌파 간격·경과와 실측 후보는 계속 선택한 이평 종류·가격 소스·캔들 기준으로 계산합니다. VWMA는 실제 교차 측정에 거래량을 사용합니다.
- 범례 머리글에는 실제 측정 이평 종류를, 기준값에는 **SMA 이론**을 표시합니다. 설정 미리보기와 툴팁에서도 측정 이평과 참조 이평을 구분합니다.
- 기존 EMA·Hull MA 개별 이론값을 사용한 지표도 새로고침 후 공통 SMA 참조값을 사용합니다. 저장된 이평 종류·기간·봇 조건·시작·정지 상태는 변경하지 않습니다.
