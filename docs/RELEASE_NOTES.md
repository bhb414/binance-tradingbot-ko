# 바이낸스 자동매매 v0.4.50

- **VWMA 추가**: 기본 지표 목록과 사용자 지표·봇 조건식에서 거래량 가중이동평균을 사용합니다. 일반·하이킨아시 가격, 기간·색상·표시 범위를 설정하며 다중종목과 선택 거래량 소스를 지원합니다.
- **수식 자동완성**: 단일·다중종목 조건식과 지표식에서 데이터·함수를 검색해 키보드 또는 터치로 입력합니다. 함수 인수 도움말과 한글 조합 입력을 지원합니다.
- **예제 없는 데이터·함수 삽입**: 종가 또는 SMA()처럼 빈 함수만 넣습니다. 인수·@주기·[봉 번호]는 자동 삽입하지 않으며 함수 괄호 안에 커서를 놓습니다.
- v0.4.49 중첩 SMA·표준편차·볼린저 계산 최적화를 포함합니다. 기존 계산 한도와 차트·봇 설정·매매 기록은 유지합니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.50-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기·내 지표는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
