# 바이낸스 자동매매 v0.4.54

- **전체 프로그램 파일 복구**: 파일 누락 오류가 이어지는 설치를 위해 repair.cmd와 repair.ps1을 추가했습니다. 앱의 기존 모듈에 의존하지 않고 공식 배포본을 따로 내려받아 체크섬·압축 경로·문법·서버 import를 검증합니다.
- 누락·변경된 프로그램 파일을 한 번에 복구하며 원본 소스는 .runtime/backups에 보관합니다. API 키·봇 설정·매매 기록·차트·즐겨찾기·내 지표와 개인 추가 파일은 보존합니다. 실패 시 적용 전 상태로 복구합니다.
- 최신 버전에서도 파일 복구를 실행할 수 있습니다. 실행 중인 프로그램에는 적용하지 않으며, 복구 후 run.cmd로 시작합니다. 거래 조건·보유 포지션·주문 허용은 임의 변경하지 않습니다.
- **기존 설치 복구:** 별도 repair ZIP을 풀어 repair.cmd와 repair.ps1 두 파일을 run.cmd 옆에 넣고 repair.cmd를 실행하세요. Node.js 24 이상만 필요하며 Git은 필요 없습니다.
