# 바이낸스 자동매매 v0.4.93

- 주기분석 예상 영역에서 자동으로 뜨던 큰 툴팁이 십자선·드래그·확대 조작을 가로막던 문제를 수정합니다.
- 십자선을 옮기는 동안에는 해당 주기분석 범례에 **N봉 후 · N배 변동률**만 표시합니다. 별도 박스가 차트 위를 덮지 않아 예상 영역에서도 그대로 드래그해 이동하고 확대할 수 있습니다.
- 예상 영역을 클릭하면 교차 필요가격 상세 툴팁을 열어 고정합니다. 툴팁 안의 버튼·스크롤은 기존대로 동작하며 가려진 차트나 지표 범례로 클릭을 전달하지 않습니다.
- 기존 교차 필요가격 역산·표시 배수·예상 화살표·실시간 갱신·봇·주문·예산 설정은 유지합니다.
