# 바이낸스 자동매매 v0.4.83

- **이평 돌파 예상**을 **이평 예상**으로 바꾸고, 두 선의 교차를 전제로 하던 안내를 제거했습니다.
- 이평묶음처럼 최대 다섯 선을 체크박스로 선택합니다. 기본 기간은 5·20·60·120·220봉이며 각 선의 이평 종류·기간·색상을 따로 정할 수 있습니다.
- SMA·EMA·VWMA·KAMA·Hull MA를 지원합니다. 예상 봉 수·기울기 비교 봉 수·기준봉·가격 소스·캔들 기준은 선택한 선에 함께 적용합니다.
- 실선은 이평, 오른쪽 점선은 최근 기울기를 연장한 예상 경로입니다. 실제 미래 가격이나 돌파 확률이 아닙니다. 범례에는 선택한 이평의 종류·기간·색상을 한 번씩 표시합니다.
- 기존 두 이평의 종류·기간·실선·예상선 스타일과 표시 여부, 예상 범위·기울기·기준봉을 보존해 새 형식으로 옮깁니다. 추가 세 선은 해제한 상태로 보관합니다.
- 모든 선을 해제하거나 묶음 전체를 숨겨도 개별 설정은 유지됩니다. 직전 완성봉 기준 예상은 진행봉 가격·거래량이 바뀌어도 변하지 않습니다.
