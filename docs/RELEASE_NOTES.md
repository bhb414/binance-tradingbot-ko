# 바이낸스 자동매매 v0.4.98

- 봇 조건식과 차트 수식의 상향돌파·하향돌파를 주기분석과 같은 기준으로 통일합니다.
- 같은 값·수치 오차 구간에서는 마지막 확인 방향을 유지하고 실제 반대편으로 넘어간 봉에서만 참입니다. 위→같음→위, 아래→같음→아래는 제외하며 실제 미세 교차는 인정합니다.
- 문법을 그대로 사용하며 별도의 재접촉 보완식 없이 돌파 함수만으로 같은 기준을 적용할 수 있습니다. 함수 도움말과 수식 해설에 변경된 판정을 명시합니다.
- 완성봉·다중 종목·데이터 누락·발생 횟수·가상 다음 봉·모든 이평 종류의 일치를 검증했습니다. 기존 주문 행동·예산·봉 주기 설정은 유지합니다.
