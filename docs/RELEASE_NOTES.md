# 바이낸스 자동매매 v0.4.99

- 차트 상단을 **종목 검색 → 가격 → 주기 → 캔들 → 지표 → 체결 → 라벨 → 자동 맞추기 → 전체화면** 순서의 한 줄로 정리했습니다.
- 여러 주기 버튼을 드롭다운으로 통합했습니다. 모바일에서는 도구 모음을 좌우로 넘기며 메뉴는 화면 안에 표시합니다.
- 각 지표 범례를 왼쪽부터 한 줄씩 일정하게 정렬하고 삭제 아이콘을 휴지통으로 바꿨습니다.
- 지표 창에 현재 추가된 지표 목록을 표시합니다. 목록에서 설정·숨김·표시·삭제를 바로 할 수 있습니다.
- 데스크톱·모바일·전체화면과 새로고침 후 설정 유지를 확인했습니다. 서버를 재시작하지 않고 적용할 수 있는 화면 변경입니다.
