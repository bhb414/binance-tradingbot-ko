# 바이낸스 자동매매 v0.4.51

- **다음봉(계산식, 시가, 고가, 저가, 종가, 거래량 선택)** 추가. 숫자·이평·사용자 수식으로 지정한 일반 OHLC 1봉을 추가한 뒤 지표·조건 결과를 현재 시점에 계산합니다. 실제 미래 데이터를 읽거나 가격을 예측하지 않습니다.
- 가정한 OHLC로 하이킨아시를 다시 계산하며 SMA·EMA·볼린저·RSI·ATR·VWMA·NW 등을 조합합니다. 거래량 미지정은 미확인으로 유지합니다.
- @주기·과거 참조·단일/다중종목 소스, 빈 함수 자동완성·인수 도움말·명시적 지표 예제를 지원합니다. 미래 봉 누출·원본 수정 없이 실제 봉 추가 계산과 일치하는지 검증합니다.
- 기존 지표·봇 조건·예산·매매 기록은 자동 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.51-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기·내 지표는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
