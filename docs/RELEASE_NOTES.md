# 바이낸스 자동매매 v0.4.68

- 사용자 지표에 **매수신호("이름", 조건)**·**매도신호("이름", 조건)**를 추가했습니다. 이평 교차 등 자유로운 조건이 참인 봉에 화살표와 이름을 표시합니다. 선과 함께 쓰거나 신호만 작성할 수 있습니다.
- 매수는 기본 초록 ↑·캔들 아래, 매도는 빨강 ↓·캔들 위이며 스타일 탭에서 표시 여부·색상·위치·크기를 조절합니다. 신호는 가격 차트에 표시하고 선은 지정한 패널을 사용합니다.
- 지표 만들기 예제, 데이터·함수 추가와 자동완성·인수 도움말에 신호 문법을 추가했습니다. 기존 수식·스크립트와 저장 지표는 유지합니다.
- 진행봉 신호는 값에 따라 변할 수 있고 조건 뒤 [1]은 이전 봉 조건을 현재 봉에 표시합니다. 차트 표시 전용이며 주문은 전송하지 않습니다. 체결 B/S 표시와 독립적입니다.
