# 바이낸스 자동매매 v0.4.63

- **일목균형표**: 전환선·기준선·선행스팬 A/B와 구름, 후행스팬을 추가했습니다. 기간과 앞뒤 표시 이동을 설정할 수 있습니다. 실제 봉 데이터를 이동하거나 미래 가격을 읽지 않습니다.
- **이평 돌파 예상**: 단기·장기 이평과 최근 기울기를 연장한 미래 예상 점선을 표시합니다. 기본값은 하이킨 종가 VWMA 6·SMA 55, 최근 3봉 기울기, 직전 완성봉에서 3봉 뒤까지입니다. 예상 범위 안에서 선형 교차가 있는지 표시하며 확률·확정 신호가 아닙니다.
- **간단 스크립트**: 기존 수식 지표를 유지하면서 변수와 최대 6개 선을 사용하는 스크립트를 추가했습니다. 이름 = 수식, 선("이름", 수식, 표시이동), 예상선("이름", 수식, 예상봉수, 비교봉수, 기준봉)을 사용합니다. 예제 선택·실시간 문법 검사·함수 도움말·기기 공통 내 지표 저장을 지원합니다.
- 조건(판단, 참일 때 값, 거짓일 때 값), 최고(데이터, 봉수), 최저(데이터, 봉수)를 지원합니다. 스크립트는 기존 수식 엔진으로 계산하고 임의 JavaScript나 외부 통신을 실행하지 않습니다.
- 차트와 지표 저장 기능 변경입니다. 기존 봇 조건·운용예산·보유 포지션·키·매매 기록은 변경하지 않습니다. 서버 재시작 후 새로고침해 주세요.
