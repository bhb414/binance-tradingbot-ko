# 바이낸스 자동매매 v0.4.48

- **백분위수(데이터, 봉 수, 백분위)**를 추가해 과거 관측값의 분포 범위를 사용자 지표·봇 조건식에서 계산합니다. 선형 보간·기기 공통 수식 저장·@주기·[1]·다중종목 소스를 지원합니다.
- **NW 차이값 중앙 90%** 상·하단 예제 추가. 각 봉의 하이킨종가 − 그때 NW를 사용하고, 직전 완성 100봉의 95·5백분위수를 현재 NW에 더합니다. 현재 봉은 기준 분포에서 제외하고 최초 200봉부터 표시합니다.
- 과거 차이값 분포와 미래 가격 포함 확률을 구분하는 도움말 제공. 누락값·범위·계산량·미래값에 의한 과거 변경을 검증하며 슬라이딩 정렬 창으로 계산량을 제한합니다.
- 기존 지표 목록·차트 설정·봇 조건·매매 기록은 자동으로 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.48-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기·내 지표는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
