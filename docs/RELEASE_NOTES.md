# 바이낸스 자동매매 v0.4.38

- 미체결 대기 시간이 지나면 다른 조회·봇 작업 사이에서도 먼저 처리합니다. REST 시세 조회 주기와 별개로 주문 기한을 약 1초 간격으로 확인합니다.
- 대기 중인 통계·수수료 조회보다 주문·취소·포지션 검증 요청을 먼저 전송합니다.
- 정지·청산 우선순위와 취소 확인 후 실제 잔량만 한 번 전환하는 처리를 유지합니다. 단일·여러 종목 봇에 적용됩니다.
- 기한 발견·취소 확인·주문 접수 시각과 최근 API 큐 대기/처리 시간을 기록합니다.
- v0.4.37의 접속 주소 간 차트 지표 설정 공유도 포함합니다.

설정한 대기 시간은 체결 완료 보장 시간이 아닙니다. 진행 중인 요청·거래소 응답·취소 확인·호출 제한에 따라 추가 시간이 필요할 수 있습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.38-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록은 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
