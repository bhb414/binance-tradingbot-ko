# 바이낸스 자동매매 v0.4.36

Node.js 24 이상이 필요한 Windows용 개인계좌 자동매매 앱입니다.

- 설정의 업데이트 확인과 npm run update:check는 Git 설치 없이 새 릴리즈 버전을 조회합니다.
- 현재 버전·최신 릴리즈 버전·Windows ZIP 다운로드 링크를 표시합니다.
- 실제 update.cmd 업데이트에는 Git for Windows가 필요하다는 안내를 분명히 했습니다. 업데이트 적용 방식과 개인 데이터 보존은 그대로 유지합니다.
- v0.4.35의 Windows 실행 창 종료 오류 수정과 이전 TP/SL 체결 대기 오정지 수정을 포함합니다.

첨부된 **binance-tradingbot-ko-v0.4.36-windows.zip**을 전부 압축 해제하고 **run.cmd**를 실행하세요. SHA256SUMS.txt는 ZIP의 검증값입니다.

기존 사용자는 Git for Windows 설치 후 프로그램을 종료하고 update.cmd로 업데이트합니다. 키·봇 설정·매매 기록은 .runtime 폴더에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
