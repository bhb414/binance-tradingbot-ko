# 바이낸스 자동매매 v0.4.53

- **Git 없이 실제 업데이트**: update.cmd가 공식 Windows 릴리즈 ZIP과 SHA256 체크섬을 내려받아 검증하고 적용합니다. Node.js 24 이상만 있으면 됩니다. Git 저장소가 없는 ZIP 설치도 지원합니다.
- **기록 보존과 복구**: 키·봇 설정·매매 기록·차트·즐겨찾기·내 지표는 보존합니다. 교체 전 원본을 백업하고 적용 실패 시 복구합니다. 중간에 전원이 꺼졌다면 update.cmd를 다시 실행해 복구할 수 있습니다.
- 실행 중에는 업데이트를 적용하지 않으며, 로컬 소스 변경이나 파일 충돌이 있으면 덮어쓰지 않고 안내합니다. 직접 소스를 관리하는 개발자용 Git 업데이트는 --source 옵션으로 유지합니다.
- Windows 실행창이 업데이트 중 자기 파일이 교체되어도 정상 종료 코드와 결과 안내를 유지하도록 수정했습니다.

**기존 update.cmd가 Git 설치를 요구한다면:** 이번 Windows ZIP을 한 번 내려받아 프로그램 종료 후 기존 폴더에 덮어쓰세요. **.runtime 폴더는 삭제하지 마세요.** 이후부터는 Git 없이 update.cmd를 사용할 수 있습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.53-windows.zip** · Node.js 24 이상. 거래 조건과 보유 포지션은 자동 변경하지 않습니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
