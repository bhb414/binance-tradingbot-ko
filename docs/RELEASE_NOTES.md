# 바이낸스 자동매매 v0.4.58

- **손실 이월 방식 선택**: 계산 예산이 0 아래로 내려간 손실을 계속 누적하거나, 계산 예산을 0에서 멈추고 초과 손실을 예산 계산에서 이월하지 않도록 선택할 수 있습니다. 매매 기록·통계의 실제 손실은 유지합니다.
- **손실 복구 중 이익 반영 선택**: 복구에도 설정 비율을 적용하는 기존 방식과, 손실 복구분은 100% 반영하고 남은 이익만 설정 비율로 더하는 방식을 지원합니다. 늘어난 계산 예산에서 발생한 손실도 추적합니다.
- **공통 예산 처리**: 단일·다중종목, 앱 주문·외부 정리의 체결과 USDT 수수료를 같은 기준으로 반영합니다. 설정·복사·재시작 시 정책과 예산 계산 상태를 보존하고 예산 기준 재설정 시 복구 대상을 초기화합니다.
- 기존 봇의 기본 계산은 유지합니다. 선택 변경은 저장 후 새로 확정되는 손익에 적용합니다. 0에서 멈춤을 선택하면 기존 음수 계산 예산도 저장 시 0으로 맞추며 실제 손익 기록은 변경하지 않습니다. 지갑 잔고·주문 가능 잔액의 비율 예산에는 이 선택을 별도로 적용하지 않습니다.
