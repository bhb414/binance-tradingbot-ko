# 바이낸스 자동매매 v0.4.69

- **배경("이름", 조건)**으로 조건에 해당하는 봉의 가격 차트 배경을 세로로 칠합니다. 교차한 봉 한 칸 또는 조건 유지 구간을 표시하고 색상·투명도를 설정합니다. 배경은 선·신호 한도와 별도로 최대 6개입니다.
- **화살표("글자", 조건)**를 추가했습니다. 매수·매도 구분 없이 글자를 지정하고 빈 문자열로 숨길 수 있습니다. 스타일에서 방향·위치·크기·색상·쌓기 순서를 조절합니다.
- 같은 봉의 화살표는 캔들 위·아래에 세로로 쌓입니다. 작은 순서부터 봉 가까이에 배치하며 충분한 표시 여백을 확보합니다. 기존 매수신호·매도신호 문법도 유지합니다.
- 새 예제와 자동완성·인수 도움말을 추가했습니다. 기존 지표·봇 설정은 자동 변경하지 않습니다. 새 출력은 차트 표시 전용이며 주문은 전송하지 않습니다.
