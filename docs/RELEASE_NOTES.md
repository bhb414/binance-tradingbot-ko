# 바이낸스 자동매매 v0.4.42

- 차트 지표 목록에 **DMI(+DI·-DI·ADX), ADX 단독, CCI, MFI, 볼린저 밴드폭(BBW), 볼린저 %B**를 추가했습니다. 기존 보조지표는 유지합니다.
- 기간·기준선·가격 소스·일반/하이킨아시 기준·색상·선 굵기·표시 봉주기를 설정하고 서버에 저장합니다.
- DMI 값은 +DI·-DI·ADX 이름과 색상을 함께 표시하며, 각 선 클릭 시 해당 봉의 값을 툴팁에서 확인합니다. 모바일 DMI 값은 별도 줄로 표시합니다.
- 보조지표 축의 정밀도를 종목 가격과 분리했습니다. 준비 봉 부족·0 나눗셈·자금 흐름 부재는 빈 값으로 유지하고 선을 연결하지 않습니다.
- 자동매매 조건·주문 설정은 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.42-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록은 .runtime에 보존됩니다.
