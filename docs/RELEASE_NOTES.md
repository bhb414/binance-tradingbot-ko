# 바이낸스 자동매매 v0.4.79

- KAMA(카우프만 적응 이동평균)와 HMA/HullMA(헐 이동평균)를 기본 지표·수식·스크립트·봇 조건 함수에 추가했습니다. 이평 묶음에서도 두 종류를 선택할 수 있습니다.
- 주기추정(값, 조회봉수, 최소주기, 최대주기), 교차간격(단기, 장기), 경과봉수(조건)를 추가했습니다. 스니펫 목록과 인수 설명에서 사용할 수 있습니다.
- 교차 주기 분석 지표에서 한 바퀴 추정·최근 완료된 교차 간격·현재 경과를 구분합니다. 기본은 7·15이평과 직전 완성봉입니다. 배수 보기에서는 ¼·½·1·2·3·4배 기준선을 표시합니다.
- 주기 추정은 과거 창의 선형 추세를 제거한 자기상관 봉우리와 정현파 적합도를 함께 사용합니다. 평탄·선형 추세·불명확한 반복은 미확인으로 표시하며, 미래 교차를 예측하거나 고정된 시장 주기를 보장하지 않습니다.
- KAMA는 최초 단순평균으로 시작하고 기본 평활 기간은 2·30입니다. HMA의 절반·제곱근 기간은 소수점 버림(최소 1봉)입니다. 두 지표 모두 거래량 가중 VWMA와 구분합니다.
- 기존 지표 설정·봇 조건·주문은 변경하지 않습니다.
