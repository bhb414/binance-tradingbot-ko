# 바이낸스 자동매매 v0.4.86

- **주기분석 → 스타일 → 경과선**에서 **골든크로스 이후 색상**과 **데드크로스 이후 색상**을 각각 설정합니다. 단기 이평이 장기 이평을 상향돌파한 뒤는 골든, 하향돌파한 뒤는 데드 색상을 다음 반대 돌파까지 유지합니다.
- 범례에도 **골든 경과 / 데드 경과**와 해당 색을 표시합니다. 캔들을 선택하면 그 시점의 방향과 경과를 보여줍니다.
- 봉 수·배수 표시 모두 같은 방향 기준을 사용합니다. 직전 완성봉 설정은 방향과 경과 모두 직전 봉을 사용하며, 단순 접촉이나 같은 방향 재돌파로 경과를 다시 시작하지 않습니다.
- 기존 지표의 색상·두께·표시 설정과 교차 간격·예상 계산값은 보존합니다. 처음 조회한 봉의 이평 위치만으로 돌파가 발생했다고 가정하지 않습니다.
