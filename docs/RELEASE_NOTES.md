# 바이낸스 자동매매 v0.4.43

- 종목 즐겨찾기를 브라우저별 저장에서 **서버 공통 저장**으로 변경했습니다. PC·같은 Wi-Fi·휴대폰이 같은 목록을 사용합니다.
- 기존 브라우저의 목록은 첫 접속 시 공통 목록에 합치고 원래 값도 보존합니다. 이전 목록은 중복 가져오지 않으며, 서버에서 삭제한 별이 오래된 목록 때문에 복원되지 않도록 처리합니다.
- 종목별 추가·삭제를 반영해 동시 수정 시 다른 기기의 변경을 덮어쓰지 않습니다. 시장별 즐겨찾기와 빈 목록을 유지합니다.
- 종목 검색에 서버 저장·동기화 상태와 다시 불러오기 버튼을 추가했습니다. 서버 재시작·파일 복원·저장 실패·인증 검사를 포함했습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.43-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
