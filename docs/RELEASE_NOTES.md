# 바이낸스 자동매매 v0.4.84

- **이평 예상**에서 기울기 유지, 현재 종가, 최근 N봉 고가·저가, 단기·장기 이평 현재값, 마지막 교차 당시 종가를 선택할 수 있습니다. 가격 가정은 기준봉에서 고정해 이후 가상 봉에도 반복합니다.
- 포함할 후보를 체크해 **후보 중 최단 교차**, **고가·저가 중 최단**, **가정 종가 평균 후 재계산**, **교차 봉수 평균**을 선택합니다. 교차하지 않는 후보는 봉수 평균에서 제외하고 포함 개수를 표시합니다.
- 교차를 비교할 두 이평, 표시 봉 수와 별도의 검색 범위, 고저가 범위, 기울기 비교 봉 수를 정합니다. 선택된 가정 가격·남은 교차 봉수·남은 배수·예상 종료 경과를 보여줍니다. 접촉과 반대편 교차를 구분합니다.
- **주기분석**의 기존 간격선 자리에서 **이전 완료 경과 / 현재 시나리오의 예상 종료 경과 / 현재 예상 남은 교차 / 기존 교차 간격**을 선택합니다. 현재 시나리오 값은 매 봉 재계산되어 불규칙하게 변하며, 기존 기준·경과선은 유지합니다.
- **직전 종료 경과는 최소·평균 후보에 포함하지 않습니다.** 마지막 교차 당시 종가는 별도의 가격 가정입니다. 이전 완료 경과는 실제 교차 간격에서 1봉을 뺀 값입니다.
- 기존 이평 예상의 여러 선·색상·체크 상태·기울기 방식과 주기분석의 기존 간격 설정을 보존합니다. 직전 완성봉 기준은 진행봉 변경의 영향을 받지 않습니다. 과거 데이터를 고치거나 추가하면 필요한 부분만 재계산합니다.

고정 종가 가정은 같은 OHLC의 가상 봉을 만들며 하이킨아시는 다시 계산합니다. VWMA는 기준봉 거래량을 반복합니다. 배수는 선택된 기준주기의 전체 또는 ½를 사용하며, 이평 예상은 두 기간의 공통 SMA 이론을 참조합니다. 후보 중 최단값은 실제 미래의 보장된 최솟값이 아닙니다. 봉수 평균 모드의 점선은 기여한 후보 이평 경로의 평균이라 교차 봉수 평균과 교차 위치가 다를 수 있습니다.
