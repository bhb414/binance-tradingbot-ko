# 바이낸스 자동매매 v0.4.61

- 봇 목록에서 여는 실제 정지 확인창과 버튼 연결을 완전 정지 동작에 맞췄습니다. 정지된 봇에 거래소 주문이 남아 있을 때도 정지 버튼으로 취소할 수 있습니다.

- **정지는 자동 매매 전체 중지**: 정지 버튼과 정지 조건 행동은 신규 진입·정리 조건·소프트웨어 TP/SL·보호 주문 재등록·잔량 시장가 전환을 모두 중지합니다. 보유 포지션은 유지합니다.
- **이 봇의 주문 취소**: 정지와 설정 저장 시 해당 봇의 미체결 진입·정리 주문 및 거래소 TP/SL 주문을 취소합니다. 다른 봇과 별도 수동 주문은 취소하지 않습니다. 취소가 확정되지 않거나 이미 체결 중이면 ‘정지 · 주문 취소 확인 중’으로 표시하고 재확인합니다. 확인 전에는 재시작할 수 없습니다.
- **정지 상태 보존**: 재시작·저장 장애 복구·다중종목 봇에서도 자동 청산이 다시 실행되지 않게 했습니다. 이미 접수된 체결과 수수료·외부 매매 대조는 계속 반영합니다. 사용자가 직접 요청하는 정리 주문은 정지 상태에서도 가능합니다.
- 봇 목록·모달·정지 행동 도움말을 새 동작에 맞췄습니다. 시작을 눌러야 자동 매매가 재개됩니다. 설정 저장도 봇 정지 및 소유 주문 취소를 수행합니다.
