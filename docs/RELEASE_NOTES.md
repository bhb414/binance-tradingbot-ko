# 바이낸스 자동매매 v0.4.65

- **지갑 증가 구간마다 예산 조정 · USDT**를 단일·다중종목 봇에 추가했습니다. 시작 예산과 지갑 한 구간, 한 구간당 예산 조정액을 금액으로 설정합니다.
- 지갑 +200 USDT마다 예산 +10 USDT인 예에서 한 번에 +500이면 2구간을 적용해 +20, 남은 100은 다음 구간에 유지합니다. 여러 구간을 한꺼번에 반영하며 기준·현재 구간 예산은 재시작 후에도 보존합니다.
- 기본은 증액만 하며 감소 시 감액도 별도 선택할 수 있습니다. 최소·최대 예산, 현재 구간 기준 지갑과 다음 증액까지 남은 금액을 표시합니다. 보관 중에는 구간을 누적하지 않고 운용 복귀 시 현재 지갑을 새 기준으로 잡습니다.
- 전체 USDT 선물지갑의 확정 금액을 기준으로 하고 미실현손익은 제외합니다. 다른 봇·수동 거래의 확정손익과 입출금도 반영하며 이 봇 손익은 중복 반영하지 않습니다. 기존 보유 수량은 유지하고 새 진입 한도에 적용합니다.
- 기존 예산 방식·봇 조건·키·포지션·기록은 자동 변경하지 않습니다. 서버 재시작 후 새로고침해 선택하세요.
