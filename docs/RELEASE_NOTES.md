# 바이낸스 자동매매 v0.4.41

- 예산 지정 방식에 **현재 주문 가능 잔액의 비율 · %**를 추가했습니다. 단일·여러 종목 봇 모두 지원합니다. 기존 금액·전체 지갑 잔고 비율 옵션은 유지합니다.
- 매 주문 준비 시 최신 주문 가능 잔액으로 운용한도를 계산하며, 이 봇의 보유·예약 증거금을 되돌려 더해 체결 후 한도가 이중으로 줄지 않게 합니다. 계산 기준은 전체 USDT 지갑 잔고 이내입니다.
- 설정 화면에 계산 기준 잔액·비율·목표 한도를 표시하고, 해당 방식에서는 금액 기준 손익 재투자를 비활성화합니다. 기존 포지션 수량은 유지합니다.
- 잔액 부족 시 감시 유지·회복 후 진입, 다중종목 배분, 저장·재시작·복사, 삭제 봇의 통계 기준 보존을 검증했습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.41-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록은 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
