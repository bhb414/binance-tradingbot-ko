# 바이낸스 자동매매 v0.4.56

- **봇 목록에 보유 포지션 표시**: 종목·롱/숏·수량·진입평단을 각 봇 아래에 표시합니다. 다중종목 봇은 보유 종목마다 표시하고, 정지 중인 보유분도 유지합니다. 계좌 총량 대신 해당 봇의 배정 수량과 평단을 사용합니다.
- **계좌 그래프의 이전 기록 안내**: 기록 시작 시각과 이전 기록 유무를 그래프 위에서 바로 확인합니다. 이미 모든 기록이 보이면 버튼을 숨기는 대신 이전 기록 없음으로 안내합니다. 과거에 수집하지 않은 잔고를 생성하는 기능은 아닙니다.
- **그래프 표시 개선**: 초기 크기 결정 후 저장된 구간을 화면에 맞추고, 수동 확대·이동은 유지합니다. 지갑 잔고를 선명한 파란 실선으로 바꾸고 각 선의 마지막 저장 금액을 범례에 표시합니다.
- 화면 표시 변경이며 봇 설정·주문·계좌 기록 간격을 자동 변경하지 않습니다. 새로고침 후 반영됩니다.
