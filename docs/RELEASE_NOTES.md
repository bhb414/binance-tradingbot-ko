# 바이낸스 자동매매 v0.4.62

- **증거금 부족은 진입 대기로 전환**: 바이낸스가 신규 진입을 증거금 부족(-2019)으로 확정 거절하면 봇을 정지하지 않습니다. 보유 포지션의 정리 조건과 TP/SL 관리를 계속하고, 최소 5→10→20→30초 대기 후 설정한 감시 주기에 맞춰 현재 조건과 주문 가능 금액을 다시 확인합니다.
- **실패한 진입 신호 복원**: 확정 거절이 진입 완료로 기록되지 않게 했습니다. 조건이 해제됐거나 봇을 정지한 경우에는 재주문하지 않습니다. 시간초과·접수 불명·다른 주문 거절은 이 재시도 대상으로 취급하지 않습니다. 정리 주문과 보호 주문의 오류도 별도로 처리합니다.
- **주문 비용을 포함한 수량 계산**: 자동 진입과 지정가 잔량의 시장가 전환에서 마크가격 차이에 따른 개시 손실, 시장가 가정가격, 계좌의 실제 수수료율을 고려합니다. 비용을 포함해 봇의 남은 한도와 현재 주문 가능 금액 안에서 수량을 계산합니다. 수수료율은 기존 캐시를 사용하므로 매초 추가 조회하지 않습니다.
- **재발 원인 확인 정보 저장**: 새 진입 주문마다 계산에 사용한 주문 가능 금액·마크가격·수수료율·예상 비용을 로컬 주문 기록에 보관합니다. 기존 봇 설정·예산과 거래 기록은 유지됩니다. 이전 거절로 정지된 봇은 임의로 다시 시작하지 않습니다.
