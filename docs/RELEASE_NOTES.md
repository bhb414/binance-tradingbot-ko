# 바이낸스 자동매매 v0.4.78

- 차트의 과거 봉을 500개씩 추가로 불러옵니다. 왼쪽 끝으로 이동하면 자동 조회하며, 차트 아래 이전 봉 버튼으로도 더 과거를 볼 수 있습니다. 홈·확대 차트 모두 지원합니다.
- 과거 봉을 붙일 때 보던 시점과 확대 비율을 유지하고, 실시간 시세 갱신 후에도 불러온 과거 봉을 유지합니다. 버튼으로 불러오면 새로 읽은 과거 구간으로 이동합니다.
- 종목·시장·봉 주기별로 데이터를 분리하고 중복·동시 요청을 막습니다. 과거 조회는 캔들 데이터만 요청하며 서버에 캐시합니다. 오류가 나도 현재 차트는 보존하고 재시도할 수 있습니다.
- 거래소에서 더 이전 데이터를 반환하지 않으면 이전 봉 없음으로 표시합니다. 봇 조건·주문 동작은 변경하지 않습니다.
