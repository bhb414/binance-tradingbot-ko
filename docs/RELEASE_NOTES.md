# 바이낸스 자동매매 v0.4.80

- 교차 주기 분석의 기준주기를 **실측 후보 / 이론 기준** 중 선택할 수 있습니다. 기존 설정은 실측 후보 방식으로 유지됩니다.
- 이론 기준은 SMA·EMA·Hull MA 쌍의 복소 주파수 응답 차이가 가장 강한 파동 길이입니다. SMA 7·15의 한 바퀴는 약 20.15봉이며, 실제 시장의 반복 주기나 교차 시점을 보장하는 값은 아닙니다.
- VWMA·KAMA는 가중치가 봉마다 바뀌므로 이론 기준을 지원하지 않습니다. 선택한 경우 원인을 표시하며 실측 후보로 임의 전환하지 않습니다.
- 봉 수 보기와 배수 보기 모두 선택한 기준을 사용합니다. 전체·½ 중 사용자가 고른 길이를 1배로 계산하며 실제 돌파 간격은 그대로 측정합니다.
- 범례·툴팁·설정 미리보기에 이론/실측 후보와 실제 기준 봉 수를 표시합니다. 실측 주기 미확인 시 데이터 부족과 반복성 미충족을 구분하고, 배수 대기 중에도 원래 간격·경과 봉 수를 표시합니다.
- 기존 지표·봇 조건·운용 설정은 자동 변경하지 않습니다.
