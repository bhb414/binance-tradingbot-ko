## Windows 초기 공개판

수식으로 조건과 행동을 설정하는 바이낸스 USDT 무기한 선물 봇 작업실입니다.

### 다운로드·실행

1. 아래 Assets에서 binance-tradingbot-ko-v0.3.0-windows.zip을 받습니다.
2. Node.js 24 이상을 설치한 Windows에서 모두 압축 해제하고 run.cmd를 실행합니다.
3. 설정에서 본인의 API 키를 등록합니다. 배포본에는 계좌·봇·매매 기록이 들어 있지 않습니다.
4. 자동 업데이트에는 Git for Windows가 필요합니다. 종료 후 update.cmd로 업데이트합니다.

SHA256SUMS.txt에서 ZIP 파일의 SHA-256을 확인할 수 있습니다.

### 검토·보완

- 호출 제한·조회 장애 시 대기/복구, 중복 주문·불확실 응답 복구 검증
- 정리·정지 조건을 신규 진입 조건보다 먼저 평가
- 저장되는 주문 허용 토글과 재시작 복원, 조회 경고 별도 표시
- ZIP 파일 대조와 자동 업데이트, 개인 데이터 제외 패키징
- 새 데이터 폴더와 배포 ZIP의 Windows 시작 동작 검증

### 범위

Windows 전용 초기 공개판입니다. 모의 거래소 검사와 로컬 실행 확인을 진행했으며, 실제 주문 체결·거래 성과를 보증하는 검증은 아닙니다. REST 조회이므로 지연·호출 제한 중 조건식 진입/청산이 늦어질 수 있습니다. 전체 사용법과 검토 결과는 저장소 문서를 확인해 주세요.
