# 바이낸스 자동매매 v0.4.59

- **예산 기준 표현 명확화**: ‘전체 선물 USDT 지갑 금액의 비율’과 ‘현재 주문 가능 금액의 비율’을 구분합니다. 전체 지갑 금액은 포지션·미체결 주문에 사용한 증거금도 포함하며 미실현손익은 제외합니다. 계산 방식과 저장된 예산 설정은 바꾸지 않습니다.
- **계좌 추이 시간축 수정**: 하루 간격의 과거 기록과 분·초 단위의 상세 기록을 실제 경과 시간으로 배치합니다. 점 개수에 따라 가로 간격이 바뀌어 모양이 왜곡되던 현상을 수정합니다. 과거 일별 지갑은 점선·원으로, 직접 관측한 지갑·평가잔고는 실선으로 표시하며 미수집 구간은 이어 채우지 않습니다.
- **새로고침 시 보던 범위 복원**: 전체 기록·상세기록 확대·직접 확대/이동 범위를 이 브라우저에 저장합니다. 기록 주기를 변경해도 과거 기록과 표시 범위를 유지합니다. 이전 시점으로 복원할 때 필요한 저장 기록도 추가 조회합니다.
- 화면 표시 변경입니다. 기존 계좌 기록·예산·주문·봇 운용과 기록 주기는 자동 변경하지 않으며 새로고침 후 반영됩니다.
