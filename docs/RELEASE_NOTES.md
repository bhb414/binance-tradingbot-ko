# 바이낸스 자동매매 v0.4.40

- 매매 기록·통계에서 삭제된 봇을 따로 선택해 개별 통계·거래 내역·손익 그래프를 조회합니다.
- 앞으로 삭제하는 단일·여러 종목 봇은 이름·삭제 시점 기준예산·통계 초기화 정보·구성원을 보존합니다. 운용 목록과 예산에서는 제외됩니다.
- 이미 삭제된 봇은 남아 있는 체결 기록으로 복원합니다. 이름을 확인할 수 없으면 종목명과 식별자로 표시하며, 삭제 전 기준예산이 없는 경우 누적 예산 대비 수익률은 미확인으로 표시합니다.
- 계좌별 기록 분리, 수수료·펀딩 확인 기준, 통계 초기화 시점을 유지합니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.40-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록은 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
