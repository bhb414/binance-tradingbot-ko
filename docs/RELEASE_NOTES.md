# 바이낸스 자동매매 v0.4.70

- 화살표·배경 각각에 **표시 대상: 가격 차트 / 이 지표 패널**을 추가했습니다. 같은 지표에서도 표시 대상을 다르게 설정할 수 있고 기존 설정은 가격 차트 표시를 유지합니다.
- 패널 화살표는 **기준선**에서 기울기20·기울기6 등 어느 선의 위·아래에 표시할지 고릅니다. 같은 기준선의 신호는 쌓기 순서대로 표시합니다.
- 이 지표 패널 선택 시 입력의 표시 위치도 별도 패널로 전환합니다. 일반 선이 없는 신호·배경 전용 패널은 0을 기준으로 표시합니다. 배경은 선택한 패널 높이만 칠합니다.
- 설정 저장·복원, 표시 대상 전환·삭제와 차트 유형·종목·주기 변경 시 표시 리소스 정리를 보완했습니다. 수식 문법과 봇 조건·예산은 변경하지 않습니다.
