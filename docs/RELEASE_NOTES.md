# 바이낸스 자동매매 v0.4.67

- 사용자 지표 생성을 **＋ 지표 만들기** 버튼과 **지표 입력** 창 하나로 통합했습니다. 수식·스크립트 유형을 따로 고르지 않습니다.
- 한 줄 계산식, 여러 줄 변수 정의, 선·예상선 출력을 입력 내용에 따라 자동 처리합니다. 예제와 데이터·함수 삽입, 입력 도움말도 한 곳에서 사용합니다.
- 기존 저장 지표를 수정하면서 두 문법을 바꿔 써도 이름·표시 위치·주기·기본 선 스타일을 유지합니다. 기존 파일 형식과 계산 기준은 그대로 사용하며 봇 조건에는 영향을 주지 않습니다.
- 스크립트 지표가 내 지표 목록에서 차트 사용 개수에 누락되던 표시를 수정했습니다.
