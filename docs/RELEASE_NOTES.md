# 바이낸스 자동매매 v0.4.88

- **주기분석의 남은 교차 예상선**을 **현재 경과 + 예상 남은 봉수** 위치에 표시합니다. 봉수·배수 표시 모두 같은 기준을 사용하고, 1봉을 빼지 않고 그대로 더합니다.
- **범례의 남은 봉수·배수는 유지**하며 예상 경과와 함께 표시합니다. 경과 0.29배에 남은 0.17배라면 선은 0.46배에 그리고, 범례에는 예상경과 0.46배 · 남은 0.17배를 표시합니다.
- 설정 이름을 **현재 경과 + 예상 남은 봉수**로 명확히 했습니다. 기존 남은 교차 설정도 다시 선택할 필요 없이 이 표시로 적용됩니다. 기존 종료 직전 경과·이전 완료 경과·교차 간격 방식과 계산 후보는 유지합니다.
- 최단·두 평균 방식, 완성봉·진행봉 기준 모두 적용합니다. 예상값은 매 봉 다시 계산하며, 남은 봉수 계산과 봇·주문·지표 설정은 바꾸지 않습니다.
- 주기분석에 **0.75배 기준 점선**을 추가합니다. 기존 0.25·0.5·1 이상 0.5 간격 점선도 유지합니다.
- **모바일 전체화면은 브라우저 안에서 차트만 확대**합니다. 브라우저·휴대폰 하단의 홈·뒤로가기 등 탐색 버튼을 숨기는 네이티브 전체화면 요청을 보내지 않습니다. PC 전체화면과 해제 버튼·Esc 동작은 유지합니다.
