# 바이낸스 자동매매 v0.4.49

- **중첩 수식 계산 최적화**: SMA·표준편차·볼린저밴드가 같은 봉의 결과를 재사용하고 창 이동 시 바뀐 부분만 갱신합니다. NW를 넣은 볼린저밴드와 이평 잔차의 표준편차가 정상 수식이어도 계산량 한도에 걸리던 문제를 개선했습니다.
- 5,000봉 NW 볼린저와 100·500봉 중첩 이평 잔차를 기존 계산 한도 안에서 처리합니다. 평균·모집단 표준편차·누락값·과거 참조·서로 다른 종목/봉주기·실시간 봉 갱신을 검증합니다.
- 차트 지표의 한도 초과 오류를 지표 계산량으로 구분합니다. 계산량·기간 제한은 유지하며 봇 조건·예산·차트 설정·내 지표·매매 기록은 자동 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.49-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기·내 지표는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
