# 바이낸스 자동매매 v0.4.100

- 차트 전체 높이는 화면 크기에 맞추고, 보조 패널은 그 안에서 높이를 나눠 씁니다. 패널을 추가하거나 숨겨도 차트 전체가 늘어나지 않습니다.
- 차트 맨 아래 **↕ 차트 높이 조절**을 드래그하면 전체 세로 길이가 바뀝니다. 전체 높이와 내부 패널 배분은 각각 저장됩니다. 두 번 누르거나 Home 키로 기본 높이로 돌아갑니다.
- 범례는 지표명·설정값과 색상별 수치를 한 줄에 표시하며 십자선 봉을 따라 갱신합니다. 마우스를 올리거나 모바일에서 선택하면 숨김·설정·휴지통·더보기 버튼이 나옵니다.
- 가격 행에 종목·주기·캔들 종류·OHLC와 선택 봉의 시가 대비 변화를 표시하고, 이평 예상의 긴 설명은 상세 툴팁으로 옮깁니다.
- **운용예산 10 USDT 최소 입력 제한을 제거했습니다.** 단일·다중종목 봇과 포지션 가져오기에 적용합니다. 실제 진입 시 레버리지를 반영한 주문금액과 종목별 최소 금액·수량 검사는 유지합니다.
