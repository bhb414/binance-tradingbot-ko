# 바이낸스 자동매매 v0.4.64

- **다른 봇 배정 후 남은 예산의 비율**을 단일·다중종목 봇 모두에 추가했습니다. 기존 금액·전체 지갑 비율·주문 가능 금액 비율은 그대로 유지됩니다.
- 전체 선물 USDT 지갑에서 기존 방식으로 운용에 포함한 봇 배정액을 뺀 공통 잔여 예산을 사용합니다. 지갑 1,000 − 기존 배정 400 = 600 USDT일 때 A·B 각각 5%는 각각 30 USDT입니다. 서로의 배정액을 다시 빼지 않고 순서와 무관하게 계산합니다.
- 이 방식의 운용 봇 비율 합계는 100% 이하로 제한합니다. 편집 중 미리 안내하고 서버 저장에서도 최신 전체 배정을 다시 검사해 동시 저장의 중복 배정을 막습니다. 정지한 운용 봇도 포함하고 보관한 봇은 제외합니다.
- 다중종목 봇은 부모 예산을 한 번 계산한 뒤 종목 비중대로 분배합니다. 계산 기준·배정 차감액·공통 잔여·비율 합계·운용한도를 설정 화면에 표시합니다. 기록·복사·삭제된 봇 통계에도 예산 기준을 유지합니다.
- 기존 봇 설정·예산 방식·조건·키·포지션·매매 기록은 자동 변경하지 않습니다. 서버 재시작 후 새로고침해 선택하세요.
