# 바이낸스 자동매매 v0.4.39

- 공유 체결 수량의 미세한 소수점 차이로 수수료 미확인 표시가 남아 예산 손익 기준 재설정이 막히던 오류를 수정했습니다.
- 이미 기록된 배정 체결과 실제 수수료가 모두 맞는 경우 확인 표시만 복구합니다. 손익·체결·수수료는 중복 반영하지 않습니다.
- 담당 종목을 바꾼 봇의 과거 주문은 원래 종목으로 조회하며, 과거 주문 대조가 현재 종목의 포지션 수량을 바꾸지 않도록 보호합니다.
- 실제 확인이 끝나지 않은 수수료는 계속 재설정을 차단하고 해당 종목·주문 번호를 안내합니다.
- v0.4.38의 미체결 기한 우선 처리와 v0.4.37의 서버 지표 저장을 포함합니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.39-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록은 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
