# 바이낸스 자동매매 v0.4.44

- **NW 인벨로프**와 **NW 기울기**를 추가했습니다. 중심선·상단·하단은 가격 차트에, 기울기는 별도 패널에 표시합니다.
- Gaussian·Rational Quadratic 커널, 계산 봉 수, Bandwidth, 가격 소스, 일반/하이킨아시, 오차 기간·밴드 배수를 설정합니다.
- 현재·과거 봉만 쓰는 비재도색 계산입니다. 진행 중인 봉은 갱신되며 준비 봉 부족·계산 불가 구간은 빈 값으로 표시합니다.
- 기울기는 봉당 변화율(%/봉)입니다. 비교 봉 수·중립 범위와 상승·하락·중립 색상을 설정하고 중심선에도 반영합니다.
- 밴드 배경색·투명도·각 선 표시·봉주기와 서버 저장을 지원합니다. 기존 지표·봇 조건·주문 설정은 유지합니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.44-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
