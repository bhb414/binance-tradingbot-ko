# 바이낸스 자동매매 v0.4.57

- **계좌 추이에 과거 잔고 추가**: ‘바이낸스 과거 불러오기’에서 최근 한 달에 제공된 일별 USDT 선물 지갑잔고를 가져와 직접 기록 시작 전 구간에 붙입니다. 가져온 기록은 서버에 계속 보관하며, 다음에도 같은 그래프에서 조회합니다.
- **과거와 현재의 기록 기준 구분**: 과거 일별 지갑잔고에는 실현손익·확정 비용·자금 이동이 반영됩니다. 과거 미실현손익·평가잔고는 생성하지 않고, 직접 관측한 구간부터 평가잔고 곡선을 표시합니다. 툴팁에서도 일별 기록과 미수집 값을 구분합니다.
- **주문 처리와 독립된 과거 조회**: 읽기 전용 SAPI 요청을 사용하고 조회 결과를 6시간 재사용합니다. 조회 실패·권한 오류로 봇을 정지하지 않으며, 기존 기록 주기와 봇 설정은 유지합니다.
