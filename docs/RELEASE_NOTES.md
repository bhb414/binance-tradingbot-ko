# 바이낸스 자동매매 v0.4.45

- **발생(조건, 봉 수, 최소, 최대)**로 최근 N봉의 조건 성립 횟수를 범위로 지정합니다. **발생횟수()**는 개수를 반환하며 최대를 생략하면 N입니다.
- **신규발생()·신규발생횟수()**로 거짓→참 전환만 따로 셉니다. 연속으로 참인 봉을 각각 세는 방식과 구분합니다.
- 단일·다중종목 조건 편집기의 함수 삽입·예제·커서 도움말과 차트 수식 지표를 지원합니다. @봉주기·[1]·다른 종목과 조합할 수 있습니다.
- 준비 봉 부족·미확인값·0 나눗셈을 0회로 오인하지 않으며 현재 시각·현재 포지션의 존재하지 않는 과거 이력 집계를 막습니다. 계산량 제한과 슬라이딩 캐시를 유지합니다.
- 기존 조건식·봇 운용·재실행·주문 설정을 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.45-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
