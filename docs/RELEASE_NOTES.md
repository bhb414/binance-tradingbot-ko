# 바이낸스 자동매매 v0.4.77

- 차트 범례를 색상 네모 + 이름이 가로로 이어지는 형태로 바꿨습니다. 공간이 부족하면 줄바꿈하며, 이동평균선 묶음은 SMA·EMA·VWMA 이름 뒤에 각 기간을 표시합니다.
- 볼린저밴드·DMI·MACD·사용자 스크립트 등 여러 선을 가진 지표도 선마다 실제 설정 색상과 이름을 표시합니다. 꺼둔 선은 제외합니다.
- 묶음 전체 숨김은 각 기간 체크와 별개인 눈 버튼으로 제공합니다. 다시 켜도 기존 기간 체크는 유지합니다. 설정·삭제는 지표별 작은 … 메뉴에 모았습니다. 선 이름을 누르면 설정을 열고, 계산값은 이름에 마우스를 올리거나 봉 선택 툴팁에서 확인할 수 있습니다.
- 홈·확대 차트·모바일·보조지표 패널에 적용하며 가격 그래프 숨김·범례 접기·기존 설정은 유지합니다. 봇·주문·지표 계산은 변경하지 않습니다.
