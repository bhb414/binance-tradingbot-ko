# 바이낸스 자동매매 v0.4.52

- **자동완성의 뒤쪽 텍스트 삭제 수정**: 커서 앞의 입력만 완성하고 이미 있는 이름 뒷부분·함수 인수·수식·주기·봉 번호를 보존합니다. 커서나 입력이 바뀐 오래된 후보는 적용하지 않습니다.
- **중첩 함수 도움말 수정**: 현재 커서가 있는 가장 안쪽 함수와 인수를 안내합니다. 안쪽 함수 이름에 오타가 있어도 바깥 함수 도움말로 넘어가지 않으며, 후보 목록과 도움말이 겹치지 않습니다.
- **편집 동작 개선**: 작은 인수 툴팁, 기본 실행 취소, 괄호 짝 자동 입력·닫는 괄호 건너뛰기·빈 괄호 삭제를 지원합니다. Enter는 후보를 선택한 경우에만 완성하고 그 외에는 줄바꿈합니다.
- 단일·다중종목 조건식과 지표식에 공통 적용합니다. 거래 엔진·봇 설정·지표식·매매 기록은 자동 변경하지 않습니다.

Windows ZIP: **binance-tradingbot-ko-v0.4.52-windows.zip** · Node.js 24 이상. 실제 update.cmd 적용에는 Git for Windows가 필요합니다. 키·봇·매매 기록·차트·즐겨찾기·내 지표는 .runtime에 보존됩니다.

개인계좌 매매만 허용하며 앱 판매·유료서비스·타인 계좌 운용은 금지합니다.
