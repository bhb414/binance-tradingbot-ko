# 바이낸스 자동매매 v0.4.72

- 사용자 지표에 **막대("이름", 값, 색기준식)** 출력을 추가했습니다. 색기준식을 생략하면 0, 지정하면 해당 선식·변수와 비교해 봉별 색상을 정합니다. 막대 입력은 별도 패널로 자동 배치합니다.
- 스타일에서 **기준 이상 색상 / 기준 미만 색상**을 각각 선택합니다. 같은 값은 기준 이상, 계산할 수 없는 기준식은 해당 막대를 비웁니다. 막대는 0부터 원값까지 표시하며 색기준식은 색 판단에만 사용합니다.
- 0 기준·이평 기준 예제와 막대() 자동완성·인수 도움말을 추가했습니다. 여러 막대·선·화살표 합계 최대 6개이며 기존 배경·신호와 함께 사용합니다.
- 서버 저장·내 지표 목록·새로고침·홈/확대 차트 및 모바일 표시를 검증했습니다. 기존 봇 조건·수식 계산과 주문 동작은 유지합니다.
