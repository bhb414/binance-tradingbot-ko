# 바이낸스 자동매매 v0.4.55

- **실제 계좌 전체 잔고 그래프**: 홈의 계좌 추이와 기록 화면에서 USDT 선물계좌의 지갑 잔고와 미실현손익 포함 평가잔고를 두 선으로 함께 봅니다. 봇 예산·봇 통계와 별개이며 수동 매매도 포함합니다.
- **기간 대신 기록 주기 설정**: 기본 1분, 5초~1일 직접 입력. 기존 관측값을 보존하고 이전 기록 불러오기·확대·이동을 지원합니다. PC·휴대폰에서 같은 기록과 설정을 공유합니다.
- 서버가 켜져 있고 데이터가 확인되면 브라우저를 닫아도 기록합니다. 기존 계좌 조회·마크가격 수신값을 사용하며 추가 바이낸스 REST 조회를 발생시키지 않습니다. 계좌 전환·오래된 계좌 정보·시세 공백에서는 잘못된 값을 기록하지 않습니다.
- 기능 적용 전 과거 평가잔고는 생성하지 않습니다. 입출금·이체를 포함한 잔고 변화이므로 순수 매매 수익률과 구별해 안내합니다. 이미 반영된 실현손익·수수료·펀딩은 지갑 잔고에 포함하며 미래 비용은 미리 차감하지 않습니다.
- 관측 기록은 .runtime/account-equity.sqlite에 저장합니다. 기존 키·봇·주문·매매 기록·차트·즐겨찾기·내 지표는 보존합니다.
