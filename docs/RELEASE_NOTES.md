# 바이낸스 자동매매 v0.4.81

- 실측 후보 차트가 강한 반복 기준을 통과한 값만 표시해 빈 화면으로 남던 문제를 수정했습니다. 강한 후보가 있으면 유지하고, 없으면 약한 파형 봉우리도 **참고 후보**로 표시합니다.
- 범례에 참고 후보 여부와 파형 설명력을 표시합니다. 툴팁에서는 최대 3개의 구별 가능한 후보와 설명력을 비교할 수 있습니다. 설명력은 파형 적합도이며 예측 확률이 아닙니다.
- 실측 후보 배수 보기도 참고 후보를 1배로 사용해 표시합니다. 실제 돌파 간격·경과 봉 수는 바뀌지 않습니다. 평탄·직선 추세·봉 부족은 계속 미확인으로 표시합니다.
- 주기 패널의 기본 높이 비율을 늘리고 설정 재로드 시 패널 사이의 높이 비율을 유지합니다.
- 봇 조건식과 지표식의 `주기추정()`은 기존의 엄격한 판정을 그대로 유지합니다. 차트 참고 후보와 주문 조건의 판정을 구분합니다.
- 이론 기준 계산·저장된 차트 설정·봇 설정·시작·정지 상태는 변경하지 않습니다. 새 화면은 새로고침 후 반영됩니다.
