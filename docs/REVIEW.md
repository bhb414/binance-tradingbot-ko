# 공개 배포 전 검토 · 2026-11-03

로컬 서버, 주문·포지션 원장, 수식/지표, 브라우저 저장, 키 저장, 설치·업데이트와 배포 패키지를 점검했습니다.

## 수정 사항

- 신규 진입 전용 봉 조회가 실패해도 평가 가능한 정리·정지 행동을 먼저 처리합니다. 같은 데이터로 확인한 진입 조건 재성립 기록은 유지합니다.
- 정지 중에는 신규 진입 수식을 조회하지 않고 보유 포지션 관리를 유지합니다.
- 신규 설치는 실전 공개 상품 조회 환경의 계좌 미연결·주문 실행 꺼짐·봇 없음으로 시작합니다.
- ZIP 첫 업데이트에서 공개 태그와 파일을 비교하며 변경·누락 파일은 덮어쓰지 않습니다.
- Windows의 짧은 경로·디렉터리 별칭에서도 실제 폴더 기준으로 Git 저장소를 판별합니다.
- 커밋된 소스만 ZIP으로 묶고 비밀정보·개인 원장을 제외하며 SHA-256을 함께 배포합니다.

## 확인 범위

- 서버: localhost, Host/Origin, 세션 토큰, 정적 경로와 요청 크기 제한
- 키: Windows DPAPI 암호화, 비밀정보 응답·원장 제외, 저장 실패/손상 복구
- 주문: 전송 전 의도 저장, 고유 ID, 응답 유실 조회, 부분 체결/취소 후 잔량
- 포지션: 외부 포지션 자동 인수 방지, 기존 봇 인수, 헤지 방향, 예산 초과 안내
- 운용: TP/SL 사용 여부, 추가 진입·중복 방지·대기, 정지/청산 우선순위
- 수식/차트: 인덱스·다중 주기·지표 계산, 차트 설정/새로고침 복원
- API 제한: 공유 요청량/대기, Retry-After, 자동 복구, 명시적 정지 보존
- 배포: Git 기록·비공개 경로 점검, 깨끗한 ZIP 실행, Git/ZIP 업데이트, 개인 데이터 보존

자동 검사는 가짜 거래소와 임시 디렉터리에서 실행하며 실제 주문을 보내지 않습니다. GitHub Actions 결과는 저장소 Actions에서 확인할 수 있습니다.

## 알려진 한계

- Windows 로컬 개인용입니다. 서비스형 다중 사용자 인증·원격 서버 배포를 제공하지 않습니다.
- 초단타 지연·실전 체결 성공·전략 수익을 보장하지 않습니다. 조회 장애·제한 중 판단과 주문 조정이 지연됩니다.
- 앱 종료 시 로컬 감시가 멈춥니다. 재시작 시 신규 진입은 직접 시작하며, 저장된 주문 허용이 켜져 있으면 보유 포지션 관리가 이어집니다.
- 크로스 예산은 자산 분리나 손실 제한 장치가 아닙니다.
- 손익·펀딩 조회 범위와 귀속이 불완전하면 미확인으로 표시합니다.
- 외부 에셋의 이용 조건은 코드 라이선스와 별개입니다.

보안 인증이나 제3자 감사 보고서는 아닙니다.
